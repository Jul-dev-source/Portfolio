# Bilder und Dateien

Lade hier die Originale in voller Auflösung hoch. Claude optimiert sie für die Website.

| Datei | Inhalt | Format |
|---|---|---|
| `portrait` | Großes Porträt für den About-Bereich | JPG oder PNG, mindestens 2000 px breit |
| `avatar` | Porträt für den Kreis im Hero (optional, sonst wird `portrait` zugeschnitten) | JPG oder PNG, quadratisch, mindestens 800 px |
| `smart-recovery` | Vorschaubild der Projektkarte | JPG oder PNG, mindestens 1600 px breit |
| `zeeus` | Vorschaubild der Projektkarte | JPG oder PNG, mindestens 1600 px breit |
| `signature.svg` | Schriftzug im Footer | SVG |
| `resume.pdf` | Lebenslauf für „Resume (PDF)“ | PDF |

Die Dateiendung ist bei den Bildern egal, nur der Name muss passen.
